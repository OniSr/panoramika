Herramientas

Asistente de captura 360 ↗ Guía la cuadrícula de fotos con el teléfono para armar una esfera. (Para interiores hoy se usa Travvir/Teleport; este asistente es el propio.)
Editor de mapa de lotes No es una página aparte: abre un recorrido con ?proyecto=<slug>&editar=1. Arriba, cada terreno con mapa de lotes ya trae el botón Editar mapa de lotes. Traza los polígonos clic a clic y usa Copiar JSON.
Portafolio público ↗ La carta de presentación para brokers. Su lista sale de proyectos/recorridos.json.

Referencia rápida

Comandos que se corren desde la carpeta del repo. El botón copia el texto tal cual; reemplaza lo que va entre < >.

  • Armar la esfera con las fotos sueltas del dron

    bash scripts/armar-esfera.sh <carpeta> <salida.webp>

  • Optimizar fotos a WebP 2:1 (lote o un solo archivo)

    python scripts/optimizar_panoramas.py <carpeta-o-archivo>

  • Tapar los polos (nadir con el logo, cenit con el color del techo)

    python scripts/tapar_polos.py <esfera.webp> <final.webp> --nadir-grados 26 --cenit-grados 32

  • Crear un recorrido nuevo a partir de la plantilla

    cp -r proyectos/_plantilla proyectos/<slug>

  • Publicar los cambios (GitHub Pages redepliega solo)

    git add -A && git commit -m "..." && git push

Cómo añadir contenido

  • Añadir una toma a un recorrido = editar el arreglo escenas de proyectos/<slug>/proyecto.json. script.js no se toca nunca.
  • Añadir un recorrido nuevo = copiar proyectos/_plantilla, mover las panorámicas a panoramas/, editar su proyecto.json y añadir una línea a proyectos/proyectos.json (para que salga en este panel).
  • Publicarlo en el portafolio público = además añadir una línea a proyectos/recorridos.json con portada y, si quieres, destacado.
  • Trazar el mapa de lotes de un terreno = abrir index.html?proyecto=<slug>&editar=1, poner los vértices clic a clic, botón Copiar JSON y pegar en la escena "tipo":"mapa-lotes" del proyecto.json.
